**Open Source** and **community-maintained** Terraform & OpenTofu modules for **outscale**.

This organization provides **reusable infrastructure modules** to help teams build, deploy, and operate workloads on **outscale** using Infrastructure as Code best practices.


## 🧱 What you’ll find here

✔️ Production-ready **Terraform modules**  
✔️ Fully compatible with **OpenTofu**  
✔️ Modular, composable, and opinionated design  
✔️ Examples with sane defaults  
✔️ Clear and consistent documentation  

## 📦 List of Modules

| Name                             | Description                                                                 | Repository |
|----------------------------------|-----------------------------------------------------------------------------|------------|
| terraform-outscale-iam           | Manage outscale IAM users, applications, policies, and permissions.         | [Link](https://github.com/tf-outscale-modules/terraform-outscale-iam) |
